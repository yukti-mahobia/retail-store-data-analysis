# Retail Store Data Analysis

## Project Overview

This project analyzes retail store data using MySQL to understand customer purchasing behavior, order trends, payment patterns, and product performance.

The analysis covers SQL concepts ranging from basic queries to advanced techniques such as joins, subqueries, and set operations.

## Tools & Technologies

- MySQL
- SQL
- Data Analysis

## Project Structure

### Database Schema
`SQL_Database_Schema.sql`

Contains the database and table creation scripts for:
- Customers
- Products
- Orders
- Order Items
- Payments
- Product Reviews

### SQL Analysis

`SQL_Level_1_Basics.sql`  
Basic SQL queries and data retrieval.

`SQL_Level_2_Filtering_and_Formatting.sql`  
Filtering, sorting, and formatting data.

`SQL_Level_3_Aggregations.sql`  
Aggregate functions and grouped analysis.

`SQL_Level_4_Joins.sql`  
Analysis using different types of SQL joins.

`SQL_Level_5_Subqueries.sql`  
Subqueries for more advanced analysis.

`SQL_Level_6_Set_Operations.sql`  
Set operations for combining query results.
